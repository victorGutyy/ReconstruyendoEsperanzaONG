# `src/components/`

Componentes de interfaz reutilizables en todo el sitio (ver `docs/07-diseno-ux-ui.md` §7).

- `ui/` — componentes de shadcn/ui personalizados con los tokens del 07 (paso 4.3).
- `layout/` — cabecera, menú, pie de página y contenedores.

Los componentes propios de un dominio van en `src/modules/<modulo>/components/`, no aquí.
